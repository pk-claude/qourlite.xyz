Optional host voice recordings go in this folder.

Name each file after the question id in questions.js, for example:
  r01.mp3  r02.mp3 ... r10.mp3   (main rounds)
  a1.mp3 ... a5.mp3              (lightning Set A)
  b1.mp3 ... b5.mp3              (lightning Set B)

When the host presses "Read aloud", the game plays the matching file.
If there is no file for that question, the browser's built-in voice reads it.
