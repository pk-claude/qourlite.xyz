Behind the scenes

This session was built by AI, overnight.

The quiz, the QR code, the live voting, the sound effects, the race track and every page on this site came from one request to an AI coding assistant (Claude), the night before this meeting. Here is the actual request:

The request, as typed (lightly trimmed)

What the AI did with it

Read the deck

All 22 slides and speaker notes, to match the quiz to each chapter and reuse the same numbers.

Checked the numbers

Against the public Q2 release and Lowe's results. Internal-only figures were kept off the public site.

Designed the games

Five quiz rounds, Fight Night, hot takes, a word cloud, Jargon Bingo and emoji reactions.

Wrote the code

Live voting over free public relays (no app, no login), a QR code, and sound effects generated in the browser.

Tested it

Ran a full game with simulated phones in a headless browser, looked at screenshots and fixed what looked wrong.

Published it

Pushed to GitHub. The site redeployed itself to qourlite.xyz. Hosting cost: $0.

Three rules that still apply

You own the facts

AI is fast, not infallible. Every number here was checked against the deck and public filings. Check yours.

Mind what you paste

Use approved tools for internal data. This public site only uses public information on purpose.

Ask for the audience

The best prompts say who is listening: "for a warehouse team", "no jargon", "one joke".

The point is not the tech. It is that a one-hour finance talk can feel like a game show, and that took one evening, not one quarter.
